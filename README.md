# Project Memory

## Product Identity
Project name: VHOTIEX AI
Description: Android-friendly AI assistant with a futuristic 3D holographic interface, black-red theme, AI chat, voice interaction, and specialized agents for coding, research, analysis, planning, and code review.

## Product Direction
The product aims to combine premium visuals with real productivity. It should feel advanced and futuristic without sacrificing clarity, speed, or accessibility.

## Key Decisions
- Mobile-first experience is a core requirement.
- Black-red dark theme is a signature brand element.
- Specialized agents should be modular and extensible.
- Voice interface is a primary interaction mode, not just an extra feature.
- Memory and session continuity are essential for trust and usability.

## Current Priorities
1. Build a polished MVP foundation
2. Setup chat and agent workflows reliably
3. Add voice interaction and memory
4. Prepare for expansion with additional agents and integrations

## Team and Workflow Notes
- Prioritize simplicity in architecture and implementation
- Keep documentation in sync with actual product behavior
- Review feature scope against user value
- Treat performance and accessibility as core quality bars

## Working Reminders
- Do not overengineer early versions
- Focus on a smooth Android experience
- Keep AI prompts structured and safe
- Always keep product documentation aligned with the app’s real state
