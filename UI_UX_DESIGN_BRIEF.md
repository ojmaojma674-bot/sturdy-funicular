# VHOTIEX AI UI/UX Design Brief

## 1. Design Goal
Create a premium, futuristic, Android-first AI interface that feels cinematic, intelligent, and highly usable. The overall experience should resemble a sci-fi command center while staying simple enough for daily interaction.

## 2. Brand Direction
- Primary palette: black, deep red, charcoal, metallic silver
- Accent palette: cyan, electric blue, subtle amber glow
- Visual style: holographic, glassmorphism, layered depth
- Tone: premium, confident, technical, futuristic

## 3. Core Experience Principles
- Minimal clutter
- Clear hierarchy
- Strong motion with restrained usage
- Fast recognition of active state
- Voice-first interaction without making text irrelevant
- Accessibility must remain strong even with dramatic visuals

## 4. Screen Structure
### Home dashboard
- Center AI core orb
- Rotating agent rings around the orb
- Quick actions and recent sessions
- Voice button with active listening indicator

### Chat screen
- Floating message cards
- User and assistant bubbles with different treatments
- Structured responses such as summaries, actions, code blocks, steps
- Suggestion chips for next actions

### Agent panel
- Agent cards for coding, research, planning, analysis, review
- Agent status, readiness, and active task context

### Memory panel
- Session summaries
- Memory clips and context tags
- Preferences and recent topics

### Security / health panel
- trust score
- service health
- anomaly notices
- recovery status

## 5. Motion and Interactions
- slow pulse on active AI core
- ring expansion when voice is active
- floating transitions between cards
- subtle scanline and shimmer effects
- quick state transitions for tool execution and response generation

## 6. Microinteraction Guidelines
- Buttons should respond with subtle glow or scale changes
- Active agent selection should feel decisive and animated
- Loading states should communicate thinking clearly without creating confusion
- Alerts should be visible but not disruptive

## 7. Accessibility Requirements
- Contrast ratios should remain readable in dark mode
- Large tap targets for mobile users
- Voice feedback should be optional and controllable
- Text labeling must remain clear for screen readers
- Theme should support reduced motion and simpler modes

## 8. Design QA Checklist
- App must feel premium on a phone screen
- Voice and text inputs must be equally discoverable
- Users must understand which agent is active
- Security and status panels must be readable and calm
- Product must remain usable during animations and transitions

## 9. Success Criteria
The UI is successful when users feel the app is advanced, expressive, and trustworthy while still being easy to use in everyday mobile tasks.
