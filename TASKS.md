# Design System

## 1. Design Goal
Create a futuristic luxury AI experience that feels intelligent, premium, and efficient. The visual language should be immersive, dark, and high-contrast while staying readable on Android devices.

## 2. Core Visual Style
### Theme
- Background: mostly black with deep graphite tones
- Accent: red and crimson glow
- Highlights: cyan or silver for depth and futuristic contrast
- Motion: subtle glow, pulse, and layered depth effects

### Interface Language
- Glassmorphism or holographic panels
- Layered cards and floating surfaces
- Minimal but expressive motion
- Strong typography hierarchy

## 3. Layout System
- Mobile-first layout optimized for one-hand use
- Chat as primary activity
- Persistent bottom navigation or action dock
- Floating actions for voice and new chat
- Stories or status cards for agent modes

## 4. Screen Concepts
### Home / Chat
- Top bar with app title and active agent
- Conversation list or chat area
- Quick actions for prompts
- Input box with voice and send controls

### Agent Selector
- Cards for Coding, Research, Analysis, Planning, Review
- Icon, label, and short description
- Selected state with active glow effect

### Voice Mode
- Large microphone button
- Animated waveform or sound visualization
- Listening status and transcript preview

### Settings / Profile
- Theme controls
- Voice settings
- Privacy options
- Memory preferences

## 5. Component Guidelines
- Rounded corners for panel surfaces
- Strong shadow and ambient glow for depth
- Bright accent lines for active UI state
- Clear contrast between primary and secondary actions
- Large touch targets for mobile safety

## 6. Typography
- High readability sans-serif family
- Bold headers for AI status and sections
- Medium weights for conversation and summaries
- Clear spacing between prompts and replies

## 7. Interaction Design
- Smooth animated responses
- Loading states with subtle holographic pulse
- Context chips for selected agent or mode
- Minimal but useful microinteractions

## 8. Accessibility
- Ensure text contrast meets mobile readability standards
- Provide screen reader labels for buttons and voice actions
- Support larger text or dynamic font sizing
- Avoid excessive flashing or aggressive motion

## 9. UX Principles
- Make AI feel helpful and trustworthy
- Keep user confusion low
- Minimize manual setup friction
- Respect context and continuity in conversations

## 10. Final Design Direction
The experience should feel like a cinematic AI command center: premium, intelligent, high-tech, and practical enough for everyday Android use.
