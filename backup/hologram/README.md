# VHOTIEX Hologram + Animation Backup

This folder keeps a clean backup of the futuristic hologram UI used for the VHOTIEX AI dashboard.

Files:
- `hologram-ui.css` — visual treatment for the holographic interface
- `hologram-ui.js` — motion, particle, and mouse-parallax setup

How to use:
1. Copy the contents of `hologram-ui.css` into `web/styles.css`.
2. Copy the contents of `hologram-ui.js` into `web/app.js`.
3. Add the markup from the live `web/index.html` hero section to include the `hologram-visual` container.

This backup preserves the working version before enhancements or future redesign iterations.
