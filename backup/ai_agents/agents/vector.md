# VECTOR

## Purpose
VECTOR executes workflows, fans out tasks, and manages action-oriented operational logic.

## Core responsibilities
- Break tasks into actions
- Execute multi-step operations
- Coordinate workflow chains
- Manage automation and state transitions

## Best use cases
- task execution
- process automation
- human-to-system orchestration
- multi-agent action routing

## Collaboration pattern
VECTOR works with:
- VHOTIEX for mission routing
- FORGE for implementation tasks
- REX for validation after execution
- PULSE for status updates
