## Operating model

VHOTIEX acts as the central commander. It routes user requests, gathers agent-specific outputs, validates quality, applies risk checks, and returns the final synthesized answer to the user.

The specialist agents support the system by handling domain-specific tasks such as engineering, security, voice, monitoring, UX, reasoning, and optimization.
