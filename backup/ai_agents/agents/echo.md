# ECHO

## Purpose
ECHO is the voice and conversational interaction agent responsible for speech recognition, voice commands, and natural-language interaction.

## Core responsibilities
- Convert speech to text
- Detect intent from spoken commands
- Support interactive audio-based workflows
- Maintain conversational context during listening sessions

## Best use cases
- voice input
- command-driven assistant actions
- hands-free interaction
- conversational UX flows

## Collaboration pattern
ECHO partners with:
- PULSE for notifications and voice status updates
- VHOTIEX for final request interpretation
- VECTOR for command execution
- SPECTRA for voice-driven UI flow
