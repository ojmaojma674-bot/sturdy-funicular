# PULSE

## Purpose
PULSE monitors live system state, sends notifications, and keeps the platform aware of time-sensitive changes.

## Core responsibilities
- Track real-time status
- Monitor system health and events
- Trigger alerts for important operational changes
- Keep the user informed in near real time

## Best use cases
- app status monitoring
- maintenance notifications
- anomaly alerts
- operational dashboards

## Collaboration pattern
PULSE works with:
- VHOTIEX for prioritization and escalation
- HELIOS for system analytics
- REX for recovery and issue monitoring
- VECTOR for live workflow status updates
