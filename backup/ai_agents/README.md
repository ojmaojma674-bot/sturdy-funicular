# AI Agent Backup

This backup folder stores the canonical definitions for the VHOTIEX multi-agent system and its operational specialists.

## Purpose

- preserve the complete agent roster
- maintain a reference copy of agent responsibilities
- provide an offline backup for orchestration logic and planning
- support future migration into a larger runtime or database-backed agent registry

## Agent hierarchy

- VHOTIEX — Commander / orchestrator
- TITAN — heavy compute and large-scale reasoning
- ECHO — voice recognition and conversational input
- PULSE — real-time monitoring and notifications
- SPECTRA — UI/UX and holographic design intelligence
- VECTOR — workflow execution and automation
- REX — testing, validation, and recovery
- QUANTUM — advanced reasoning and strategic analysis
- PROMETHEUS — experimental tools and prototypes
- HELIOS — knowledge synthesis and system analytics
- FORGE — engineering and software build execution
- AEGIS — security, policy, and vulnerability detection
- EVOLVE — self-improvement and optimization

## Backup status

This is a structured reference backup intended to remain stable as the production backend evolves.
